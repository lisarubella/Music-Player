## 📱 Install on Your Devices

### Desktop (Windows/Mac/Linux)
1. Run `npm run dev` in terminal
2. Open the app in browser
3. Click **Install** button (in address bar)
4. App runs like native program

### iPhone/iPad
1. Open Safari
2. Visit app URL
3. Tap **Share** → **Add to Home Screen**
4. Tap **Add** to confirm
5. App appears on home screen

### Android Phone
1. Open Chrome
2. Visit app URL
3. Tap **Menu** (⋮) → **Install app**
4. Confirm installation
5. App appears in app drawer

## 🐛 Troubleshooting

### "npm: command not found"
→ Install Node.js from https://nodejs.org

### App won't start
```powershell
Remove-Item node_modules -Recurse -Force
npm install
npm run dev
```

### Installation button not showing
→ Ensure HTTPS is used (Vercel/Netlify auto-enable this)

### Works locally but not after deployment
→ Check DEPLOYMENT.md for hosting-specific setup
